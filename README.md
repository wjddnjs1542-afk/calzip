# 계산집 v1.0

슬로건: **필요한 계산, 계산집에서.**

## 포함 계산기
1. 평수 계산기
2. 나이 계산기
3. 날짜 계산기
4. 환율 계산기
5. 단위 계산기
6. BMI 계산기
7. 연봉 계산기
8. 퇴직금 계산기

## 로컬 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포
1. 새 공개 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 최상위에 업로드합니다.
3. 저장소 `Settings → Pages`로 이동합니다.
4. `Deploy from a branch`, 브랜치 `main`, 폴더 `/(root)`를 선택합니다.
5. 배포 주소가 생성될 때까지 잠시 기다립니다.

## 배포 전 수정 권장
- `sitemap.xml` 안의 임시 주소를 실제 GitHub Pages 주소로 교체
- 개인정보처리방침의 운영자 이메일 추가
- AdSense 승인 후 광고 코드와 `ads.txt` 값 추가
- 연봉·퇴직금 계산 공식을 최신 공식 기준으로 고도화


## v0.2 변경사항
- 평수 계산기를 `평형 계산기`로 고도화
- 전용면적 기준 정확한 평수 표시
- 공급면적 기준 예상 평형 동시 표시
- 전용률 75%, 78%, 80% 및 직접 입력 지원
- 59㎡, 74㎡, 84㎡, 101㎡ 빠른 선택
- 전용면적과 공급면적 차이 설명 추가

## v0.3 변경사항
- 나이·날짜·퇴직금 날짜 입력을 연/월/일 분리형으로 변경
- 연도 4자리 입력 후 월, 월 2자리 입력 후 일로 자동 이동
- D-Day에 주년·다음 주년 계산 추가
- 단위 계산 버튼 제거, 입력 즉시 자동 환산
- 단위 계산 UI를 좌측 입력 / 우측 결과 구조로 단순화
- 모든 금액 입력에 한국식 천 단위 쉼표 적용
- BMI 결과 안내를 생활습관 우선·전문의 상담 중심으로 개선
- 2026년 사회보험 요율을 반영한 연봉 실수령액 상세 표시

## v0.4 변경사항
- 월 실수령액 계산은 세전 연봉 1개만 입력
- 연봉 상승 계산을 두 방식으로 분리
  - 기존 연봉 + 변경 연봉 → 상승률 계산
  - 기존 연봉 + 상승률 → 변경 연봉 계산
- 연간 증감액, 월 세전 증감액, 변경 월 세전액 동시 표시

## v0.5 변경사항
- D-Day 결과에 `n주년 (n+1년차)` 동시 표시
- 퇴직금 결과에 근속기간을 `몇 년 몇 개월 며칠`과 총 일수로 표시
- 퇴직금 임금 입력 및 결과 금액에 천 단위 쉼표 적용
- BMI에 성별 선택 추가
  - BMI 공식과 등급은 남녀 동일
  - 성별은 복부비만 허리둘레 안내에 활용
- 대한비만학회 한국인 성인 BMI 기준 적용
  - 저체중: 18.5 미만
  - 정상: 18.5~22.9
  - 비만 전 단계: 23.0~24.9
  - 1단계 비만: 25.0~29.9
  - 2단계 비만: 30.0~34.9
  - 3단계 비만: 35.0 이상
- 키 기준 정상체중 범위와 체중 증감 참고값 추가
- 복부비만 기준: 남성 90cm 이상, 여성 85cm 이상 안내
- 생활습관 우선 및 의료전문가 상담 중심의 비만치료 안내 강화

## v1.0 최종 정리
- 8개 계산기 기능·모바일 UI 정리
- 연봉 실수령 계산 공식을 모든 연봉 탭에서 공통 사용
- 월 비과세액, 가족 수, 자녀 수, 원천징수 비율 선택 지원
- 연봉 상승 계산 결과에 기존·변경 월 실수령액과 실수령 증감액 표시
- 2026년 국민연금 4.75% 근로자 부담, 건강보험 3.595% 근로자 부담,
  장기요양보험 및 고용보험을 반영
- 소득세는 공제조건을 반영한 추정치로 표시
